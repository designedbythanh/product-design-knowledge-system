# Example: Northbeam

A filled-in copy of the templates for Northbeam, a fictional hiring tool for recruiting agencies. It's the same product as the cases in the [skills library's evals](https://github.com/designedbythanh/ai-skills-library-product-design/tree/main/evals), so you can see the context and what the skills did with it side by side.

- [`PRODUCT.md`](PRODUCT.md): with Sources, both markers (`Not provided`, `⚠️ Not validated`) and an optional Domain section
- [`guidelines.md`](guidelines.md): short on purpose. Only rules specific to Northbeam
- [`decision-log.md`](decision-log.md): one cross-feature decision, referenced from the brief
- [`briefs/settings-fields.md`](briefs/settings-fields.md): a brief after four skills ran, with a rejected suggestion and its Log

The brief's Log follows the skills chain described in the library's [REAL-USE.md](https://github.com/designedbythanh/ai-skills-library-product-design/blob/main/REAL-USE.md), rewritten as Northbeam (the dates are invented). Everything else is invented for the example.
